# 발표 덱 (초안)

`index.html` — SVP 해커톤 발표 슬라이드. **외부 라이브러리 의존 없는 단일 파일**이라 브라우저로 바로 열린다.

## 보기 / 발표

브라우저로 `docs/deck/index.html`를 연다.

- **← → (또는 스페이스)** 슬라이드 넘김
- **F** 전체화면 (발표 시)
- 화면 **왼쪽 클릭 = 이전 / 나머지 클릭 = 다음**

## PDF로 내보내기

브라우저에서 **인쇄(Ctrl/⌘+P) → PDF로 저장**. 슬라이드 1장당 1페이지로 출력된다.
(PowerPoint가 필요하면 PDF/이미지를 슬라이드에 붙여 넣는다.)
